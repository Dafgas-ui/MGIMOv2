# Продуктовые субагенты «Стратега Фабрики продуктов»

Каталог специализированных субагентов, привлекаемых главным оркестратором для решения изолированных задач продуктовой аналитики, исследования и критического аудита.

## Состав каталога

| Файл субагента | Роль и назначение | Профиль модели | Права доступа |
|---|---|---|---|
| [`research-analyst.md`](./research-analyst.md) | Первичный разбор объёмных документов, таблиц и веб-источников, структурирование фактов и локаторов | `flash` / `flash_lite` | Read-Only |
| [`synthetic-respondent.md`](./synthetic-respondent.md) | Моделирование пользовательских интервью, стресс-тест барьеров восприятия и поиск гипотез | `flash` / `flash_lite` | Read-Only |
| [`strategy-auditor.md`](./strategy-auditor.md) | Независимый ревизор («адвокат дьявола»), проверка честности доказательств, непротиворечивости и схем | `pro` / `inherit` | Read-Only |

---

## Способы запуска и интеграции

### 1. В среде Google Antigravity
Оркестратор объявляет и запускает субагента через встроенные инструменты платформы:

```python
# 1. Регистрация типа субагента (при первом обращении)
define_subagent(
    Name="research-analyst",
    Description="Первичный разбор источников данных с изоляцией untrusted_data",
    SystemPrompt="<содержимое файла agents/research-analyst.md>",
    EnableWriteTools=False,
    EnableSubagentTools=False,
    EnableMCPTools=False
)

# 2. Вызов субагента на конкретную задачу с маршрутизацией модели
invoke_subagent(
    TypeName="research-analyst",
    Role="Research Analyst",
    Model="flash",  # Экономичная модель для поточного анализа
    Prompt="Проанализируй файл projects/<case>/sources/billing_funnel_q3.csv и извлеки метрики конверсии...",
    Workspace="inherit"
)
```

Для критического аудита (`strategy-auditor`) в параметре `Model` передаётся `"pro"` или `"inherit"`.

### 2. В среде Claude Code
При работе в Claude Code субагенты запускаются через инструмент `Task` (Subagent):
```bash
claude "Проведи критический аудит стратегии кейса projects/<case>, руководствуясь правилами agents/strategy-auditor.md"
```
Контекст субагента изолирован от основного диалога, права на запись ограничиваются флагом сессии.

### 3. В среде Cursor / VS Code / Codex
В средах с поддержкой системных промптов и чат-агентов содержимое Markdown-файла передаётся как специализированная инструкция роли (`System Message` или `@file` упоминание в агентском режиме Composer). Субагент получает файл источника или реестр кейса на вход и возвращает нормализованный JSON-ответ для сохранения в реестрах.

---

## Принципы изоляции
1. **Экономия контекста:** тяжелые тексты источников и протоколы синтетических диалогов не перегружают контекст главного оркестратора.
2. **Контроль записи:** субагенты работают в режиме `Read-Only` и возвращают данные в виде структурированных кандидатов. Решение о сохранении в реестр (`upsert-node`) принимает главный агент с использованием детерминированного CLI.
3. **Безопасность:** весь недоверенный контент анализируется с жестким соблюдением границ `trust_boundary: "untrusted_data"`.
