# Сценарий видео (до 10 минут): сквозной путь демонстрационного проекта

**Проект:** «Стратег Фабрики продуктов» · **Кейс:** `projects/connect_family_devices` (официальный учебный бриф «Связь для близких и собственных устройств»)
**Хронометраж:** 9:30 (лимит конкурса — 10 минут) · **Формат:** запись экрана IDE (Cursor / Claude Code / Antigravity) + голос за кадром.

Видео должно показать: **запрос → работа агента → варианты → стратегия → продолжение после перерыва**. Всё, что ускорено или смонтировано, подписывается на экране
(«ускорено ×8»). Ничего не выдаётся за реальные данные: на экране и в голосе — «учебные данные брифа».

## Подготовка (до записи, не входит в 10 минут)

```bash
git clone https://github.com/Dafgas-ui/MGIMOv2.git && cd MGIMOv2
python tools/check_coordination.py && python -m unittest discover -s tests      # 58 тестов, OK
# чистая копия для живого прогона (исходный кейс не трогаем):
mkdir -p projects/live_demo/sources && cp projects/connect_family_devices/sources/* projects/live_demo/sources/
```

Откройте корень репозитория в среде. Шрифт 125–150 %, окно 1920×1080, уведомления выключить. Тайм-код на телефоне: прогон агента занимает ~15–20 минут —
запишите его целиком, в видео оставьте ускоренные фрагменты с подписью.

## Что не показывать и чего не говорить

- Не называть расходы «копейками» и не обещать выигрыш во времени: сравнение с аналитиком вручную не измерялось.
- Не показывать в кадре реальные ключи, токены и личные окна.
- Не утверждать, что интервью реальные: в этом кейсе интервью не проводились.
- Не называть оценку баллов — решение жюри.

## Запасной вариант (если живой прогон агента не получился)

Показать повторяемые команды ядра на готовом кейсе (`status`, `resume`, `invalidate-source` на копии кейса, `export-html`) и открыть готовые документы.
В подписи указать: «демонстрация ядра и результатов; живой диалог с моделью показан в [таймкод]/не записывался». Так зритель не примет скрипт за работу модели.
